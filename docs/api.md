# REST API

Взаимодействие клиентской и серверной частей происходит через REST API с передачей данных в формате JSON. Для работы с API необходима авторизация, обычный пользователь имеет доступ только к своим бронированиям, а сотрудник с правами персонала может просматривать все записи. При изменении данных через сессию требуется CSRF-токен

## Маршруты

Общий префикс: `/api/rentals/`

| Метод | Маршрут | Назначение | Тело запроса | Ответ | Ошибки |
|---|---|---|---|---|---|
| GET | /equipment/ | Список оборудования | Нет | 200, список техники | 403 |
| GET | /equipment/{id}/ | Просмотр оборудования | Нет | 200, данные техники | 403, 404 |
| GET | /bookings/ | Список бронирований | Нет | 200, список заявок | 403 |
| GET | /bookings/{id}/ | Просмотр бронирования | Нет | 200, данные заявки | 403, 404 |
| POST | /bookings/ | Создание бронирования | equipment, project_title, start_date, end_date, notes (необязательно) | 201, заявка со статусом draft | 400, 403 |
| PUT | /bookings/{id}/ | Обновление бронирования | Данные заявки | 200, обновлённая заявка | 400, 403, 404 |
| PATCH | /bookings/{id}/ | Частичное обновление | Например, `{"notes": "Нужен штатив"}` | 200, обновлённая заявка | 400, 403, 404 |
| DELETE | /bookings/{id}/ | Удаление бронирования | Нет | 204, без содержимого | 403, 404 |
| POST | /bookings/{id}/transition/ | Изменение статуса | `{"target_status": "confirmed"}` | 200, заявка со статусом confirmed | 400, 403, 404 |

Для фильтрации бронирований используются параметры `status` и `category`, а изменение статуса выполняется через отдельный маршрут, поскольку при подтверждении бронирования необходимо проверить наличие свободной техники, изменить её доступное количество и сохранить событие в журнале

Ошибка 400 возникает при некорректных данных или недопустимом переходе, 403 при отсутствии доступа или ошибке CSRF, 404 если объект не найден или недоступен пользователю

## Проверка

Работу API можно проверить во вкладке Network браузера, а сохранение данных в административной панели Django. Для просмотра автоматически сформированной документации используется [Swagger](http://127.0.0.1:8000/api/docs/)
