# Типичные ошибки и диагностика

| Проблема | Причина | Решение |
|---|---|---|
| ModuleNotFoundError | Не установлены зависимости | Выполнить `make install` |
| Ошибка DJANGO_SECRET_KEY | Не настроено окружение | Проверить наличие .env и значения переменных |
| no such table | Не выполнены миграции | Выполнить `make migrate` |
| Ошибка 403 при изменении бронирования | Нет авторизации или CSRF-токена | Проверить вход в систему и передачу токена |
| Ошибка подключения к PostgreSQL | Неверный DATABASE_URL | Проверить строку подключения в настройках Render |
